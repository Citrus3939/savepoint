# Savepoint：微信小程序文字人生模拟器

这是一个“先跑通核心循环”的微信小程序原型：玩家从出生开始，随着年龄增长不断遇到文字事件，做出选择，并因为选择获得不同属性、标签、连续事件、成就和故事线索。

当前版本不接图片、不接服务器、不接真实 AI，先把玩法骨架跑起来，方便继续添加事件。

## 当前已实现

- 主界面
  - 开始人生
  - 成就 / 天赋
  - 事件编辑器
  - 分享到微信好友
  - 退出
- 人生事件系统
  - 年龄段触发
  - 优先级
  - 随机触发
  - 连续事件
  - 属性变化
  - 人生标签
- 成就系统
  - 事件选择可以解锁成就
  - 达成条件也可以自动解锁成就
- 天赋 / 故事线索系统
  - 成就解锁的不是强度天赋，而是“故事线索”
  - 每次开始人生会随机带入一部分已解锁线索
  - 线索只解锁特殊事件，不直接加属性，避免玩家只追求固定最强组合
- 事件编辑器
  - 可以在小程序里添加本机试玩事件
  - 支持标题、正文、年龄段、优先级、年龄推进、两个选择和属性变化
- 结局评语
  - 当前是本地规则生成的“AI 风格评语”
  - 之后可以替换成真正的 AI 接口

## 如何运行

1. 安装并打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本仓库根目录。
4. AppID 可以先用测试号或游客模式。
5. 点击编译。

项目入口文件：

- `app.json`
- `pages/index/index`

## 如何添加正式事件

正式事件写在：

```text
data/events.js
```

一个事件大概长这样：

```js
{
  id: "childhood_friend",
  title: "操场边的哭声",
  text: "六岁那年，你在操场边看见一个同学因为被嘲笑而哭。",
  minAge: 6,
  maxAge: 12,
  priority: 80,
  ageAdvance: 2,
  choices: [
    {
      text: "留下来陪对方一会儿",
      statChanges: {
        relationships: 2,
        happiness: 1
      },
      addTags: ["loyal_friend"],
      unlockAchievements: ["warm_heart"],
      nextEventId: "friend_secret"
    }
  ]
}
```

常用字段：

- `id`：事件唯一名字，不能重复
- `title`：事件标题
- `text`：事件正文
- `minAge` / `maxAge`：触发年龄范围
- `priority`：优先级，数字越大越容易先触发
- `chance`：随机概率，例如 `0.45`
- `ageAdvance`：选择后推进几岁
- `requires.tags`：需要玩家有某个标签才会出现
- `requires.talents`：需要某个故事线索才会出现
- `choices`：玩家选项
- `nextEventId`：选择后强制接到下一个连续事件
- `unlockAchievements`：选择后解锁成就

## 如何添加成就和故事线索

成就和线索写在：

```text
data/achievements.js
```

设计原则：

- 成就可以作为收集目标。
- 成就解锁“故事线索”。
- 故事线索不直接加属性。
- 故事线索只让特殊事件进入事件池。

这样玩家不会为了最强数值只选择固定天赋，而是为了体验不同人生去解锁新故事。

## 事件编辑器说明

小程序里的“事件编辑器”适合快速试玩。

它添加的事件保存在微信本地缓存里，不会自动写回 `data/events.js`。如果某个试玩事件效果不错，可以再把它整理成正式事件，放进 `data/events.js`。

## 关于排行榜和 AI 评语

当前结局会根据年龄、健康、快乐、知识、人际、金钱、成就数量生成一个本地评分和评语。

后续可以扩展成：

- 本地休闲排行榜：只记录自己的几段人生
- 好友排行榜：需要接入微信能力和后端
- AI 评语：把人生记录发给 AI 接口，生成更文学化的总结

建议不要只用“分数”衡量人生。可以把排行榜拆成多个维度：

- 最长寿人生
- 最快乐人生
- 最有钱人生
- 朋友最多的人生
- 最戏剧化人生
- 最普通但温暖的人生

这样更符合休闲体验玩法，而不是单纯追求最强路线。
