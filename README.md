# Savepoint：微信小程序文字人生模拟器

这是一个“先跑通核心循环”的微信小程序原型：玩家从出生开始，随着年龄增长不断遇到文字事件，做出选择，并因为选择获得不同属性、标签、连续事件、成就和故事线索。

当前版本不接图片、不接服务器、不接真实 AI，先把玩法骨架跑起来，方便继续添加事件。

## 当前已实现

- 主界面
  - 开始人生
  - 成就 / 天赋
  - 事件编辑器
  - 分享到微信好友
  - 退出
- 人生事件系统
  - 年龄段触发
  - 优先级
  - 随机触发
  - 连续事件
  - 属性变化
  - 人生标签
- 成就系统
  - 事件选择可以解锁成就
  - 达成条件也可以自动解锁成就
- 天赋 / 故事线索系统
  - 成就解锁的不是强度天赋，而是“故事线索”
  - 每次开始人生会随机带入一部分已解锁线索
  - 线索只解锁特殊事件，不直接加属性，避免玩家只追求固定最强组合
- 事件编辑器
  - 可以在小程序里添加本机试玩事件
  - 支持标题、正文、年龄段、优先级、年龄推进、两个选择和属性变化
- 结局评语
  - 当前是本地规则生成的“AI 风格评语”
  - 之后可以替换成真正的 AI 接口

## 如何运行

微信开发者工具只能导入“你电脑本地”的项目文件夹。所以要先把项目文件下载到你的电脑。

### 第 1 步：先把项目放到电脑上

你需要得到一个文件夹，打开后能看到这些文件：

```text
app.js
app.json
app.wxss
pages
data
utils
```

如果你是从 GitHub 下载：

1. 打开项目的 GitHub 页面。
2. 找到绿色的 `Code` 按钮。
3. 选择 `Download ZIP`。
4. 下载完成后解压。
5. 记住解压出来的文件夹位置。

这个解压出来的文件夹，就是微信开发者工具要导入的项目文件夹。

### 第 2 步：用微信开发者工具导入

1. 安装并打开微信开发者工具。
2. 选择“小程序”。
3. 选择“导入”或“导入本地项目”。
4. `项目目录` 选择刚才解压出来的整个文件夹。
   - 不要选择 `app.json` 单个文件。
   - 不要选择 `pages` 子文件夹。
   - 要选择最外层、能看到 `app.json` 的那个文件夹。
5. `AppID` 可以先选择测试号、游客模式，或者填写微信开发者工具提供的测试 AppID。
6. 项目名称可以随便填，例如 `Savepoint`。
7. 点击“导入”。
8. 进入项目后点击顶部的“编译”。

项目入口文件：

- `app.json`
- `pages/index/index`

### 如果预览时报 `INVALID_LOGIN`

如果你点“预览”时看到类似错误：

```text
Error: INVALID_LOGIN, access_token expired
appid: touristappid
```

这通常不是游戏代码问题，而是微信开发者工具的登录状态过期，或者游客 AppID 不适合做手机预览。

你可以按顺序尝试：

1. 先点“编译”，只在电脑模拟器里测试。
   - 如果模拟器能打开主界面，说明游戏本身可以运行。
2. 在微信开发者工具右上角退出登录，再重新扫码登录。
3. 重新打开项目，再点“编译”。
4. 如果还想用手机扫码“预览”，建议不要用 `touristappid`，改用：
   - 微信开发者工具提供的测试号 AppID
   - 或你自己在微信公众平台注册的小程序 AppID

简单理解：

- “编译”：在电脑里试玩，最适合现在测试原型。
- “预览”：生成二维码发到手机，需要微信登录态和 AppID 正常。

## 完全小白怎么测试

你可以先不用管代码，只按下面的顺序试玩。

### 第 1 步：确认能打开

1. 用微信开发者工具导入项目。
2. 点击顶部的“编译”。
3. 模拟器里应该看到主界面：
   - 开始人生
   - 成就 / 天赋
   - 事件编辑器
   - 分享到微信好友
   - 退出

如果主界面能看到，说明项目已经跑起来了。

### 第 2 步：测试一局人生

1. 点击“开始人生”。
2. 看到事件后，随便选一个选项。
3. 观察这些内容有没有变化：
   - 年龄是否增加
   - 健康、快乐、知识、人际、金钱是否变化
   - 是否出现新事件
   - 是否出现“新成就”提示
   - 玩到结局后是否出现人生评语

不用追求玩得好，第一轮测试只看“流程有没有断”。

### 第 3 步：测试成就和故事线索

1. 回到主界面。
2. 点击“成就 / 天赋”。
3. 看看有没有已解锁的成就。
4. 如果有故事线索，再开始新人生。
5. 新人生可能会遇到只有该线索才能触发的特殊事件。

这个系统的目标是：天赋不加战斗力，只让人生出现不同故事。

### 第 4 步：测试事件编辑器

1. 回到主界面。
2. 点击“事件编辑器”。
3. 随便填一个事件，例如：
   - 标题：雨夜的电话
   - 正文：深夜，一个很久没联系的朋友突然打来电话。
   - 最小年龄：18
   - 最大年龄：60
   - 优先级：90
   - 推进年龄：3
   - 选择 A：接起电话
   - 选择 B：假装没听见
4. 点击“保存事件”。
5. 回到主界面，开始人生，看看这个事件会不会出现。

注意：编辑器添加的是“本机试玩事件”，只保存在当前微信开发者工具里。真正要长期保留的事件，后面再整理进 `data/events.js`。

### 第 5 步：记录测试问题

试玩时建议开一个表格或文档，记录四列：

| 类型 | 你看到的问题 | 你希望变成什么样 | 严重程度 |
| --- | --- | --- | --- |
| 事件 | 某事件太早出现 | 希望 20 岁后才出现 | 中 |
| 数值 | 金钱太容易涨 | 降低赚钱选项收益 | 低 |
| 文案 | 选择不够有代入感 | 改得更像人生抉择 | 中 |
| 流程 | 玩到 30 岁后没事件 | 增加 30-50 岁事件 | 高 |

你不需要写技术原因，只要描述体验问题就够了。

## 如何添加正式事件

正式事件写在：

```text
data/events.js
```

如果你是新手，建议先看这份更详细的教程：

```text
EVENT_DESIGN_GUIDE.md
```

一个事件大概长这样：

```js
{
  id: "childhood_friend",
  title: "操场边的哭声",
  text: "六岁那年，你在操场边看见一个同学因为被嘲笑而哭。",
  minAge: 6,
  maxAge: 12,
  priority: 80,
  ageAdvance: 2,
  choices: [
    {
      text: "留下来陪对方一会儿",
      statChanges: {
        relationships: 2,
        happiness: 1
      },
      addTags: ["loyal_friend"],
      unlockAchievements: ["warm_heart"],
      nextEventId: "friend_secret"
    }
  ]
}
```

常用字段：

- `id`：事件唯一名字，不能重复
- `title`：事件标题
- `text`：事件正文
- `minAge` / `maxAge`：触发年龄范围
- `priority`：优先级，数字越大越容易先触发
- `chance`：随机概率，例如 `0.45`
- `ageAdvance`：选择后推进几岁
- `requires.tags`：需要玩家有某个标签才会出现
- `requires.talents`：需要某个故事线索才会出现
- `choices`：玩家选项
- `nextEventId`：选择后强制接到下一个连续事件
- `unlockAchievements`：选择后解锁成就

## 如何添加成就和故事线索

成就和线索写在：

```text
data/achievements.js
```

设计原则：

- 成就可以作为收集目标。
- 成就解锁“故事线索”。
- 故事线索不直接加属性。
- 故事线索只让特殊事件进入事件池。

这样玩家不会为了最强数值只选择固定天赋，而是为了体验不同人生去解锁新故事。

## 事件编辑器说明

小程序里的“事件编辑器”适合快速试玩。

它添加的事件保存在微信本地缓存里，不会自动写回 `data/events.js`。如果某个试玩事件效果不错，可以再把它整理成正式事件，放进 `data/events.js`。

## 关于排行榜和 AI 评语

当前结局会根据年龄、健康、快乐、知识、人际、金钱、成就数量生成一个本地评分和评语。

后续可以扩展成：

- 本地休闲排行榜：只记录自己的几段人生
- 好友排行榜：需要接入微信能力和后端
- AI 评语：把人生记录发给 AI 接口，生成更文学化的总结

建议不要只用“分数”衡量人生。可以把排行榜拆成多个维度：

- 最长寿人生
- 最快乐人生
- 最有钱人生
- 朋友最多的人生
- 最戏剧化人生
- 最普通但温暖的人生

这样更符合休闲体验玩法，而不是单纯追求最强路线。

## 本地测试

核心事件规则可以用 Node.js 测试：

```bash
node --test
```

如果你不熟悉命令行，可以先不跑这一步。对你来说，最重要的是用微信开发者工具试玩并记录体验问题。

## 作为游戏设计师，接下来最该做什么

建议你先不要急着做美术、排行榜和 AI。这个游戏最核心的是“事件库质量”和“人生分支的可回味程度”。

### 1. 先写 30 个事件

按人生阶段分：

- 童年：5 个
- 学生时代：5 个
- 初入社会：5 个
- 亲密关系 / 家庭：5 个
- 中年危机 / 转折：5 个
- 晚年 / 回望：5 个

每个事件先只写两个选择。不要一开始写太复杂。

### 2. 给事件打标签

每个事件想清楚它属于哪类体验：

- 温暖
- 遗憾
- 冒险
- 现实压力
- 成长
- 亲情
- 友情
- 爱情
- 职业
- 健康

这样后续才能控制“某一局人生像什么故事”。

### 3. 设计 5 条连续故事线

例如：

- 童年朋友线
- 离家去大城市线
- 长期疾病线
- 写作 / 创作线
- 照顾家人线

连续故事线会让玩家觉得“我的选择真的留下了后果”。

### 4. 不要只追求数值平衡

这个游戏不是竞技游戏。你更应该关注：

- 选择是否难以取舍
- 事件是否像真实人生
- 玩家是否愿意再开一局
- 结局评语是否能让人回想刚才的人生

数值只是辅助，不是核心。

### 5. 排行榜先做“多维人生榜”

不建议只做一个总分榜。可以设计成：

- 最长寿
- 最快乐
- 最富有
- 朋友最多
- 最有知识
- 最多遗憾
- 最多转折

这样玩家不会只追求唯一最优解。

### 6. AI 评语后面再接

现在先用本地规则评语就够了。等事件和人生记录稳定后，再把玩家一生的记录发给 AI，让 AI 生成更像“人生传记”的总结。

AI 评语可以输入这些内容：

- 玩家经历过的事件
- 每次做出的选择
- 最终属性
- 成就
- 标签
- 年龄

然后让 AI 输出：

- 一句话人生标题
- 一段温柔评语
- 三个关键词
- 如果重来一次，可能会怎样
